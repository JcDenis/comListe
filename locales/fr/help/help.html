Activation
Cochez cette case pour activer la page publique. Tant qu'elle est décochée, la page n'existe pas sur le blog.
Titre de la page public
Titre de la page publique, aussi utilisé pour le lien du widget quand son propre titre de lien est vide.
Nombre de commentaires par page
Nombre de commentaires affichés sur chaque page de la liste publique.
Ordre des commentaires
Croissant affiche les commentaires les plus anciens d'abord, décroissant les plus récents d'abord.
Widget et menu
La page publique est à l'adresse comListe du blog. Ajoutez le widget « Liste de commentaires » depuis la page Widgets, ou un item de type « Liste de commentaires » depuis la page Menu simple, pour y faire un lien.
