Activation
Check this box to enable the public page. While it is unchecked, the page does not exist on the blog.
Public page title
Title of the public page, also used for the link of the widget when its own link title is empty.
Number of comments per page
Number of comments shown on each page of the public list.
Comments order
Ascending shows the oldest comments first, descending the newest first.
Widget and menu
The public page is at the address comListe of the blog. Add the widget « Comments list » from the page Widgets, or an item of the type « Comments list » from the page Simple menu, to link to it.
